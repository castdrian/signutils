2. Purpose and audience
SignUtils is a developer tool for members of the Apple Developer Program. Producing a development or ad hoc build for test devices normally means visiting the developer portal to register an App ID, pick capabilities and devices, create a certificate signing request in Keychain Access, generate a certificate, export a .p12 and download a provisioning profile. SignUtils does all of this in one guided flow from an iPhone, iPad or Mac using the developer's own App Store Connect API key, and returns a zip with the .p12, its password and the matching .mobileprovision. It also keeps a library of every bundle created and lets developers revoke certificates, delete profiles and App IDs, edit capabilities and manage registered devices.

3. Setup and access
No login or account is needed for review. On the first screen tap "Explore the Demo". The demo runs entirely on the device against simulated App Store Connect data, so every feature works, including creating, sharing and revoking signing bundles. Steps: tap + in the Library, choose Development, pick an App ID, choose capabilities, select devices, choose "Create a new certificate", then Generate. Open the bundle in the Library to share it or revoke it. The other tabs manage certificates, profiles, App IDs and devices.
With a real account, the developer creates an API key in App Store Connect under Users and Access > Integrations, then taps "Add App Store Connect API Key" and enters the key ID, issuer ID and .p8 private key.

4. External services
SignUtils only talks to Apple's App Store Connect API (api.appstoreconnect.apple.com), authenticated with the developer's own API key. It uses no other services, no analytics, no advertising, no AI services and no servers of its own. Keys and generated private keys are stored in the Keychain.

5. Regional differences
SignUtils works the same in every region. There are no regional differences in features or content.

6. Regulated industries and third-party material
SignUtils does not operate in a regulated industry and contains no protected third-party material. It only manages the developer's own signing assets through Apple's public API.
